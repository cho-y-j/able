# ABLE 연구·작업 대기열 (QUEUE)

> **목적**: 다음에 무엇을 할지, 왜 그것인지, 무엇에 막혀 있는지.
> 착수 전 `LEDGER.md`에서 중복 여부를, `DECISIONS.md`에서 폐기 여부를 확인한다.

## 우선순위 규칙

1. **측정 장치가 거짓말하는 동안 다른 작업은 가치가 증폭되지 않는다.** 검증 인프라 우선.
2. **하나를 끝까지 관통시킨다.** 여러 축을 동시에 반쯤 만드는 것이 가장 나쁘다.
3. 위험을 키우는 작업(레버리지·실거래 확대)은 그 위험을 막는 작업보다 **뒤에** 온다.

## 상태 표기

`대기` `진행중` `차단` `완료(→LEDGER ID)` `폐기(→ADR)`

## 목표 설계 (v2) — 이 대기열이 향하는 곳

모든 항목은 아래 3축 격자의 어느 칸을 채우는 작업이다. 근거는 `DECISIONS.md` ADR-0006~0009.

**제1축 호라이즌** — 알파가 며칠에 걸쳐 소멸하는가가 비용 예산을 정하고, 비용이 자산군을 정한다.

| | 단기 1–5일 | 중기 1–12주 | 장기 3–12개월 |
|---|---|---|---|
| 알파 원천 | 수급 불균형, 유동성 충격 | **매출 서프라이즈(PEAD)**, 중기 모멘텀 | 밸류·퀄리티, 매출 추세 |
| 신호 반감기 | 1–3일 | 3–8주 | 6–18개월 |
| 왕복 비용 예산 | 0.05% 이하 | 0.3–0.4% | 1% 이상 무관 |
| → 적합 자산 | **지수선물** (거래세 없음, 양방향) | 국내 현물 | 해외 현물·ETF |
| 검증 난이도 | 비용 추정 오차가 지배 | **가장 쉬움 — 여기부터 착수** | MinBTL 큼, 단순 규칙만 |
| 목표 개별 Sharpe | 0.5–0.8 | 0.4–0.7 | 0.3–0.5 |

**제2축 자산군** — 국내 현물(중기) / 해외 현물(장기, FX 분리 필요) / 지수선물(단기, 베타 헤지).

**제3축 정보원** — 역할을 혼동하면 함정에 빠진다.

| 정보원 | 역할 | 규칙 |
|---|---|---|
| 투자자별 수급 | **1급 알파** | 한국시장 고유 데이터. 최우선 투자처 (Q-020) |
| 펀더멘털(매출) | 중기·장기 알파 | 매출 서프라이즈를 이익과 분리. point-in-time 필수 (Q-021) |
| 거래량 | **조건변수** | 방향 신호 아님. 모멘텀 가중치 조절 (Q-022) |
| 뉴스 | **필터** | 감정 점수를 진입에 연결 금지. 회피·청산에만 (Q-023) |

**제4축 결합** — 호라이즌별 고정 예산 → 주문 넷팅 → 불감대 → 변동성 타게팅 → 시차 상관 제약.
반감기를 **실측한 뒤에** 감쇠 모델을 넣는다. 순서를 바꾸지 않는다.

### [Q-020] `flow_signals.py` 를 1급 알파 모듈로 확장
- 상태: 대기
- 근거: 67행. `compute_foreign_3day_trend`가 +1/-1/0 세 값만 반환. 한국시장 고유 데이터(투자자별 순매수)를 가장 빈약하게 다루고 있다. 뉴스 함정에 대한 유일한 실질적 방어

- 차단 요인: Q-001

### [Q-021] 매출 서프라이즈 팩터 (이익과 분리)
- 상태: 대기
- 근거: PEAD는 매출 서프라이즈를 고려할 때 유의하게 커지며, 매출의 지속성이 과소평가된다. Fama-French 3팩터로 설명되지 않음
- 주의: **point-in-time 필수.** 발표일과 값을 함께 저장. 수정재공시 소급 금지
- 차단 요인: 재무데이터 소스 확정 필요

### [Q-022] 거래량을 조건변수로 재배치
- 상태: 대기
- 근거: Lee & Swaminathan(2000) — 저거래량 승자는 추세 연속, 고거래량 승자는 반전. 거래량은 방향이 아니라 지속성을 예측
- 범위: 모멘텀 알파의 가중치 조절 변수로. 독립 알파에서 제외

### [Q-023] 뉴스 필터 구현 (진입 신호 아님)
- 상태: 대기
- 근거: Barber & Odean(2008) — 개인은 주목도 기반 매수, 최고 거래량 구간에서 매수가 매도보다 29.5% 많음. 개인 주목도는 부정적 뉴스 확산을 지연
- 범위: 뉴스 + 거래량 급증 + 개인 순매수 우위 → 진입 금지·청산 우선순위 상승. 감정 점수를 진입에 연결하지 않음
- 차단 요인: Q-020 (수급 판정이 필터의 입력)
